# BITS AIML Calendar Starter

## What this is
A GitHub Pages frontend + Google Sheets CMS + Apps Script backend starter.

## Next steps
1. Put the Google Sheet tabs in place.
2. Deploy Apps Script as a web app.
3. Paste the web app URL into `config.js`.
4. Push this folder to GitHub Pages.

## Sheet tabs
- Settings
- Electives
- Deadlines
- Announcements
- Admins
- Links
